# PDF 용량 줄이기 — 8MB 제한에 걸렸을 때 (업로드 없이 무료)

보험사 앱에 진료비 영수증을 올리려는데 **"파일 용량은 8MB 이하"** 에 막힐 때가 있습니다.
관공서 민원 사이트, 회사 결재 시스템도 마찬가지입니다. 이럴 때 쓰는 무료 도구입니다.

- 도구: https://www.coding-now.com/pdf-compressor
- PDF 는 **브라우저 안에서만** 처리됩니다. 서버로 올라가지 않습니다.

## 쓰는 순서

1. PDF 를 끌어다 놓거나 눌러서 고릅니다.
2. 방식은 보통 **글자 그대로 · 사진만 다시 압축** 그대로 둡니다.
3. 올릴 곳의 제한에 맞춰 **용량 제한**을 고릅니다(예: 8 MB).
4. **PDF 줄이기**를 누르고, 검사가 끝나면 다운로드합니다.

줄여도 제한을 넘으면 한 단계 더 강하게 다시 줄이고, 그래도 넘으면 **쪽 단위로 나눠** 파일마다 제한 이하가 되게 만들어 줍니다.
보험 청구나 민원 서류는 첨부를 여러 개 받는 곳이 많아서, 큰 파일 하나가 막힐 때 나눈 파일들은 대개 올라갑니다.

## 얼마나 줄어드나 (실측)

| PDF | 원래 | 줄인 뒤 |
|---|---|---|
| 휴대폰 사진 4장 | 2.18 MB | 0.18 MB (−92%) |
| 스캔본 4쪽 | 5.12 MB | 0.93 MB (−82%) |
| 그림 많은 논문 16쪽 | 7.70 MB | 4.58 MB (−40%) |
| 글자 위주 공문서 68쪽 | 0.51 MB | 0.51 MB (−0.3%) |

PDF 용량은 대부분 그 안의 사진이 차지합니다. 그래서 사진·스캔이 많을수록 많이 줄고, 글자 위주 PDF 는 거의 줄지 않습니다.

## 깨지지 않았는지 확인

줄인 PDF 는 다시 열어 쪽수를 원본과 비교하고, 모든 쪽을 작게 그려 원본과 비교합니다.
크게 다른 쪽이 있으면 결과를 버리고 원본을 그대로 둡니다. 나눈 파일도 하나씩 같은 검사를 합니다.

## 두 가지 방식

| 방식 | 글자 선택·검색 | 잘 줄어드는 PDF |
|---|---|---|
| 글자 그대로 · 사진만 다시 압축 | 그대로 됨 | 사진·그림이 든 문서, 사진 영수증 |
| 강하게 · 페이지를 이미지로 | 안 됨 | 스캔본, 어떻게 해도 제한을 넘는 PDF |
